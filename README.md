# 💰 EarnHub

A task-based earning platform for Kenya. Complete tasks, refer friends, and earn real KSH.

## Features
- User registration & login
- Referral system (KSH 20 per referral)
- Daily Check-in (KSH 5)
- Trivia Quiz (KSH 15)
- Chat to Earn with AI (KSH 10)
- M-Pesa withdrawal

## Setup

```bash
npm install
npm run dev
```

## Deploy
Push to GitHub and import on [vercel.com](https://vercel.com).
